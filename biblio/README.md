## Description
Biblio est un projet PHP de gestion d'une bibliothèque. Il comprend trois classes principales : `Livre`, `Bibliotheque` et `Membre`.

## Contrat d'interface
- `Livre` : représente un livre.
- `Bibliotheque` : représente la bibliothèque et la gestion des livres.
- `Membre` : représente un membre de la bibliothèque.
- `autoload.php` : permet de charger automatiquement les classes PHP.
- `index.php` : sera le point d'entrée de l'application.
- `tests/` : contient les fichiers de tests du projet.
